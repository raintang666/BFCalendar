## 节气场景

用页头的「节气」切换到节气视图。

清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至、小寒、大寒二十种动效方案。参考附件中的玻璃卡片、
顶部渐隐场景、同步背光、彩色内边缘和日期光晕，以原生 Canvas 绘制。
此目录可在浏览器里逐帧查看动效。

清明是冷蓝烟雨、层叠远山与开合的油纸伞，谷雨是雨珠与新苗，立夏是荷叶与蜻蜓。
小满以逆光照亮一穗青麦。麦芒和半透明麦壳勾出轮廓，籽粒由下往上逐粒灌浆，
穗尖仍留有空隙。露珠随麦穗一起轻摆。
芒种以暖金田野衬托农人挥臂撒种，种子从手边飞出，新禾在各自的落点长出。
夏至用日晷表现日光升降和晷针影子的长短变化。正午时日影最短，
浅金色背光、玻璃边缘和日期光晕一起提亮，日期角标也有随时间移动的微型日晷。
小暑用枝上蝉与摇动的树叶表现初暑。蝉翼轻颤时，鸣声用扩散的光纹呈现，
背光和日期光晕一起提亮，选中日期左上角是小蝉角标。
大暑呈现暮蓝草岸和忽明忽暗的萤火。近处的萤火掠过时留下短尾光，
草尖上的双萤角标与玻璃背光和日期光晕一起明灭。
立秋用一棵梧桐树呈现入秋。几片叶子从不同枝头依次脱落，在风里翻转、转赭，
其中几片落到水边时荡开细波。日期左上角配一枚赭色小叶。
处暑的檐下玻璃风铃与纸坠随晚风摆动。暖铜色逐渐过渡到清风蓝，
背景、玻璃边缘和日期光晕一起变色，日期左上角配一枚小风铃。
白露的草叶在晨雾中随风摆动。露珠滑到其中一片的叶尖，随后脱离并加速滴落。
选中日期左上角配一枚托露的小芦叶。
秋分的落日和初月在远山之上短暂齐平，随后日落月升。
暖金与暮蓝在秋水里摇曳，选中日期左上角并排显示小日月。
寒露的秋菊在冷雾中逐层舒展，露水凝在几片花瓣的尖端。
选中日期左上角配一朵小菊和一滴露水。
霜降的薄霜从叶缘和柿蒂逐渐铺开，在柿面长出细小霜纹。
选中日期的左上角配一枚小柿子和一片霜晶。
立冬的炭炉从微亮的余炭烧到火旺，茶壶冒出一缕缕热气。玻璃背光随炉火转暖，
选中日期左上角配一把冒热气的小茶壶。
小雪的雪片飘过松枝，薄雪逐渐积在枝头。微风吹过时，松枝摆动并抖落一小阵雪。
选中日期左上角配一枚覆雪的小松枝和一片雪花。
大雪的雪片由疏到密，厚雪逐渐盖上山屋的屋顶和台阶，窗灯在风雪里亮起来。
选中日期左上角配一座覆雪的小屋和一扇暖窗。
冬至用一盘冬饺表现团圆。筷子夹起一只饺子，稍作停留后放回。日期左上角配一只带褶边的小饺子。
小寒的腊梅从花苞逐朵绽开，蜡黄色花瓣衬着枝头薄雪。日期左上角配一朵小腊梅和花苞。
大寒呈现带门窗和烟囱的雪屋。大雪花在屋前屋后飘落，半透明冰凌从檐下依次凝长。日期左上角配一座带冰凌的小雪屋。

清明至大寒的二十个玻璃光影已迁入 Flutter 的「节日光影」示例。

在仓库根目录启动：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory tool/holiday_glass_preview/dist
```

打开 <http://127.0.0.1:8765/>。无需安装前端依赖。

- 下方按钮切换场景及对应节日或节气日期。清明至冬至使用 2027 年日期，小寒和大寒使用紧接冬至的 2028 年 1 月日期。
- 月历支持点选日期、上月和下月，六周月份会完整显示。
- 暂停、重播和时间滑块用于比较动画各时刻。
- 系统开启减少动态效果时显示静帧；页面隐藏时停止请求动画帧。
- 节日和节气场景共用一个 `requestAnimationFrame`，每帧从时间直接计算画面。
- 字体复用项目已有的 Host Grotesk、Geist Mono，许可证随字体保留。

录制时带 `?rec` 打开页面，调用 `window.__selectTerm('duanwu')` 选择场景，
再调用 `window.__render(t)` 绘制指定秒数，`window.__LOOP` 为 13。
此模式从静帧开始，点击播放或重播即可退出录制并开始动画。

当前选中的场景按 13 秒循环播放。可以手动切换节日、节气和月份。
