# 节日与节气示例

从示例首页进入「节日光影」，在日历下方的「本月节日与节气」卡片中选择效果。
点「全部光影」可按月浏览其他场景，选择后日历会跳转到对应日期。
日历排版、日期选择和滑动换月均由项目的 `CalendarView`、
`CalendarController` 和 `CalendarComponentBuilder` 完成。

已接入飘雪、烟花、灯笼，以及立春、雨水、惊蛰、春分、清明、谷雨、
立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至、小寒、大寒二十四个节气。
示例从 2026 年 12 月打开，可用「全部光影」选择后续月份。

元旦、除夕、元宵节、劳动节、端午节、中秋节和国庆节也已接入玻璃光影。
元旦在城市上空放起烟花，除夕在檐下挂起福贴，元宵节的莲花灯随水漂动。
劳动节的塔吊依次起吊、横移、落梁，楼架窗灯逐盏亮起。端午节的桨手同步划桨，中秋节的云层移开露出圆月，国庆节的红绸在城楼上方飘动。
元旦、劳动节和国庆节的日期角标分别是蓝色台历、金色安全帽和五星红旗。
春节、除夕、元宵节、端午节、中秋节和节气使用项目已有的 `lunar` 依赖计算日期。同一天有两个节日或节气时，可用快捷入口分别查看。

清明、谷雨、立夏、小满、芒种、夏至、小暑、大暑、立秋、处暑、白露、秋分、寒露、霜降、立冬、小雪、大雪、冬至、小寒、大寒已接入玻璃光影方案，分别呈现远山纸伞与细雨、
新苗与雨珠、荷叶与蜻蜓、青麦灌浆、农人撒种与新禾、日晷与午影、树荫与蝉鸣、草岸与流萤、梧桐与落叶、晚风与风铃、芦草与晨露、日落与月升、秋菊与凝露、柿枝与薄霜、围炉煮茶、松枝与初雪、山屋与风雪、青瓷与冬饺、雪枝与腊梅、雪屋与冰凌。
玻璃光影场景共用 `holiday_glass_scene.dart` 的
原生 Canvas 绘制，使用透明背景、440px 场景渐隐、同色背光与玻璃边缘。
场景每 13 秒循环，继续由页面现有的单一时钟驱动；类名、构造参数
和日期角标绘制方法保持原有调用方式。静态光照由 `ui.Picture` 缓存并在离开时释放。

小满的青麦穗随风摆动，籽粒由下往上鼓起、亮起，灌浆进度同步提亮背光、
玻璃边缘和日期光晕。选中日期左上角绘制两颗青麦粒和一滴晨露。
芒种与网页共享 6.5 秒的撒种节拍。农人双脚站定，挥臂时种子从手边飞出，
新禾从各自的落点长出。撒种时背光、玻璃边缘和日期光晕一起提亮，
日期角标为斗笠和飞落的种子。
夏至的太阳沿弧线升降，晷针影子扫过刻度，在正午最短。浅金背光、玻璃边缘和日期光晕
随日照同步变化，选中日期左上角的微型日晷也呈现同样的日影变化。
小暑的树叶随风摆动，蝉翼颤动时，成对光纹向外扩散，带动背光、玻璃边缘和日期光晕。
选中日期左上角绘制与场景同拍的小蝉。
大暑的萤火在暮蓝草岸上远近交错，明灭间留下短尾光，草尖双萤角标随日期光晕一起变化。
立秋每轮有七片叶子从梧桐的不同枝头陆续落下。叶子边翻转边转赭，落到水边时荡起细波，
选中日期左上角绘制同形的赭色小叶。
处暑的玻璃风铃和纸坠随风错开摆动。风铃、背光、玻璃边缘和日期光晕从暖铜色逐渐转为清风蓝，
选中日期左上角绘制同拍摆动的小风铃。
白露的芦草在晨雾里错落摆动，露珠滑到叶尖后脱离并加速滴落。
选中日期左上角显示一枚托露的小芦叶。
秋分的落日与弯月在远山上短暂齐平，水面同时映出暖金和暮蓝。
背光、玻璃边缘和日期光晕跟随天色变化，日期左上角显示并排的小日月。
寒露的秋菊在冷雾中逐层舒展，瓣尖逐渐凝出水珠。日期左上角显示小菊和露珠。
霜降的薄霜沿叶缘、柿蒂和柿面长出细纹，玻璃背光随霜色转冷。日期左上角显示小柿子和霜晶。
立冬的炭火先亮起，热气随后从壶嘴升起，玻璃背光随炉火转暖。日期左上角显示冒热气的小茶壶。
小雪的薄雪逐渐积在松枝上，风起时枝条轻摆，抖落一小阵碎雪。日期左上角显示覆雪小松枝和一片雪花。
大雪的雪势由疏变密，屋顶和台阶逐渐积雪，山屋的窗灯随之亮起。日期左上角显示一座带雪檐的小屋。
冬至的木筷从右侧夹起青瓷盘上的一只饺子，稍停后放回盘中。日期左上角的小饺子也随木筷轻轻抬起。
小寒的腊梅在雪枝上逐朵绽开，花色同步映亮玻璃背光。日期左上角显示一朵小腊梅和一个花苞。
大寒的冰凌从雪屋檐下逐根凝长，大雪花从屋前屋后飘过。日期左上角显示一座带冰凌的小雪屋。

减少动态效果时，小满显示第 4.6 秒，芒种显示第 2.5 秒，夏至和小暑显示第 5.4 秒，
大暑显示第 6.75 秒，立秋显示第 4.5 秒，处暑显示第 6.6 秒，白露显示第 7.6 秒，秋分显示第 6.5 秒，寒露显示第 7.4 秒，霜降显示第 8.2 秒，立冬显示第 7.1 秒，小雪显示第 7.75 秒，大雪显示第 8.1 秒，冬至显示第 7.4 秒，小寒显示第 8.1 秒，大寒显示第 8.7 秒的静帧。
页面进入后台时停止动画。

验证命令：

```sh
flutter analyze
flutter test
flutter run --profile -d <Android 设备 ID>
```

`test/holiday_summer_test.dart` 覆盖真实 SDK 日历、不同年份的节气日期、
手机与横屏布局、两倍字号、暂停与恢复、动画时钟跨周期和静态画面。
`test/holiday_calendar_test.dart` 额外验证日期角标、真实触摸选日和滑动换月。
`test/holiday_glass_scene_test.dart` 验证玻璃场景的时间确定性、
13 秒循环、透明背景、日期角标以及原生日历集成。
